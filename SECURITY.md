# Security policy

Please do not disclose a suspected vulnerability, credential, or private data
in a public issue. Use GitHub's **Report a vulnerability** flow under the
repository's Security tab to open a private advisory. Include the affected
revision, impact, reproduction steps, and any safe mitigation you have tested.

If private advisories are unavailable, open a public issue requesting a
private reporting channel without including sensitive details. Maintainers
will acknowledge a usable report as capacity allows and coordinate disclosure
after a fix or documented mitigation is ready.

For ordinary bugs, support questions, or unsafe skill behavior that does not
require confidentiality, use the public guidance in [SUPPORT.md](SUPPORT.md).
