# Clarify

Create one visual explanation that answers the audience's main question. Reuse
supplied context; infer an ordinary audience or scope choice when reasonable
and label material assumptions. Ask only when a missing choice would change
the explanation substantially. This is an explanation method, not a mandatory
interview or approval step for unrelated work.

Separate checked and supplied facts from assumptions and uncertainty. Verify
material current claims with available primary sources when needed; preserve
useful source URLs and observation dates. Do not invent evidence to complete
a diagram.

## Produce the explanation

Return one self-contained `.html` file that works offline. Inline its CSS,
visuals and any necessary interaction. No remote assets, fonts, scripts,
tracking or companion files. Use a permitted workspace path; a request for a
local artifact already authorizes its ordinary filename and creation.

Choose the visual relationship that explains the subject: flow, comparison,
timeline, hierarchy or another useful form. Prefer readable labels and a few
connected sentences to decoration. Use semantic HTML with a document language,
useful title, main content and headings. Give SVGs or other visuals accessible
titles/descriptions and adjacent text explaining the same conclusion.

Ensure contrast, keyboard access, visible focus and non-color equivalents.
Reflow dense diagrams at narrow widths so labels stay readable. Respect reduced
motion. Provide a text-only fallback in the audience's language. Include concise
sources and material assumptions; if research was unnecessary, say that briefly.

Inspect a representative narrow and desktop rendering and any interaction that
carries the explanation. Fix readability or meaning problems and check the
changed part again; stop when the artifact meets the requested outcome. These
local checks need no separate approval. If rendering is unavailable, inspect
what is possible and report that specific evidence limit.

Return the artifact with a brief note about the audience, takeaway and material
uncertainty. If the artifact cannot be produced, return a useful text explanation
and the concrete limitation. External publishing still requires authority for
that destination and action.
