# Support

Use [GitHub Issues](https://github.com/onlinesourdough/Skills/issues) for
reproducible bugs, documentation gaps, portability problems, and focused
enhancement proposals. Include the release tag or commit, active harness and
CLI version, the affected skill, expected behavior, observed behavior, and the
smallest safe reproduction. Remove credentials and private project data.

This community project is maintained on a best-effort basis and has no support
SLA. Questions about the separate Skills Atlas application belong in the
[Skills Atlas issue tracker](https://github.com/onlinesourdough/Skills-Atlas/issues).
Confidential security reports belong in the process described by
[SECURITY.md](SECURITY.md).
